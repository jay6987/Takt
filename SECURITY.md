# Security Policy

## Supported Versions

The project currently supports security fixes for the latest development line only.

- `main`: supported
- Older tags/releases: best effort

## Reporting a Vulnerability

Please do not open public issues for unconfirmed security vulnerabilities.

Report privately by contacting the maintainers with:

1. A clear description of the issue.
2. Reproduction steps or proof of concept.
3. Potential impact assessment.
4. Any suggested mitigation.

You can use repository private reporting features when available, or contact the maintainers directly.

## Disclosure Process

1. Maintainers acknowledge receipt.
2. Issue is triaged and reproduced.
3. A fix is prepared and validated.
4. Coordinated disclosure and release notes are published.
